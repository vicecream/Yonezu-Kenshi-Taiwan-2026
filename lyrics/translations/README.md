# 米津歌曲繁中譯詞供稿

[曲目與 ID](../../docs/lyric-sources.md) · [匯入說明](../../docs/translation-import.md)

目前沒有米津版已匯入的翻譯。可提供純中文、雙語對照或有來源的 PDF，檔名建議採固定 ID，例如 Lemon.zh.txt。附上歌曲版本、譯者、原始網址、可使用依據及節錄範圍。

不必自行補時間碼，也不必強制與 LRC 行數一致；有原文對照更容易核實拆句與重複段落。沒有提供的部分保留待補，不把其他歌曲的譯者署名移過來。

sources.json、extracted-pairs.json、alignment.json 及 user-supplied.json 為空的輸入清單。取得內容後再核對並建立逐句映射，先執行匯入預覽。

舊 PDF、照片及歷史映射已保存於 [歷史封存](../../archive/fujii-kaze-2026/README.md)，不屬於米津曲庫。
